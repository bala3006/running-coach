SYSTEM OVERVIEW · LOCAL FIRST

Coach Eklavya,
under the hood.

Thunai AI connects a local Ollama model to your running context through a small FastAPI host and read-only MCP tools. The model reasons over retrieved activity and sheet data; deterministic code owns training arithmetic.

01 / REQUEST PATH

INTERFACE

Coach Eklavya UI

Local browser chat, language preference, Tamil coach warmth, and connection settings.

HTTP

LOCAL APPLICATION

FastAPI agent host

Validates chat, loads session history, builds the coach prompt, invokes MCP tools, and filters unsafe or unsupported output.

API

LOCAL MODEL

Ollama

Generates coaching responses and requests tools when useful. Model weights remain on the user's machine.

SQLite conversation history

Local message history is keyed by browser session and stored at ~/.running-coach/coach.sqlite3 by default.

Deterministic training metrics

Distance, duration, and average pace summaries are calculated in Python before the model explains them.

MCP integrations

Agent host launches each server as a local stdio subprocess.

MCP SERVER · READ ONLY

Strava

Exposes recent running activities. The Python adapter fetches activity data from the Strava API and returns a deterministic summary with the rows.

MCP SERVER · READ ONLY

Google Sheets

Reads the configured profile or training-plan range from the Sheets API. No write tools are registered.

02 / CHAT CYCLE

One turn

  1. The browser sends a message, session ID, language, and voice preference to FastAPI.
  2. The host adds recent local conversation history and discovers tools from both MCP servers.
  3. Ollama responds directly or requests a bounded number of read-only tool calls.
  4. The host returns tool results to Ollama, filters unsupported citations and generated Tamil in English-first mode, then saves the exchange locally.

03 / TRUST BOUNDARIES

What leaves the machine

  • Chat prompts and conversation history go to the configured local Ollama endpoint.
  • Strava and Google receive their own read-only API requests when the coach calls a tool.
  • OAuth access and refresh tokens are stored in the operating system credential store.
  • The app does not call a hosted LLM and exposes no plan-write or sheet-write tools.

Safety boundary

Coach Eklavya provides training guidance, not medical care. It does not diagnose injuries. For concerning symptoms it should advise stopping and seeking professional care. The integrations start read-only, and the model cannot edit your training plan.
